# SignCourse Studio · 手语课程编排工具

SignCourse Studio 是面向手语教师与复核员的课程设计工作台。教师把示范片段、手形说明、字幕、镜头角度、常见错误和练习任务组合为学习步骤；复核员逐步骤给出复核结论与退回意见。两端的稿子按持有方分开保存，互不覆盖。

## 双端分工（持有方分离）

顶部可在 **编排端 · 教师** 与 **复核端 · 复核员** 之间切换，两边各自只读写自己的本地存储：

- **编排端**（沿用原草稿键）：课程模块、学习步骤、字幕、镜头、练习等全部课程内容；撤销/重做只在编排端生效。
- **复核端**（独立键）：每个学习步骤的复核结论（通过/退回）、退回意见、整门课程退回说明、离线待补推队列、两版冲突对账区。复核端看课程内容只读。

### 离线与对账合并

- 复核端断网时仍可记意见：操作先写本机并进入待补推队列，恢复网络（或点「立即对账」）后按**步骤编号**（稳定步骤 ID + `模块-序号` 编号，如 `1-02`）对账。
- 同一步骤两边都动过：**内容认编排端、结论认复核端**，两版并排留在「对账合并」面板，复核员逐条认下编排端内容后再重新确认结论。
- 合并失败可**按侧重试**（编排端侧 / 复核端侧）；失败时本地结论原样保留，已确认的结论先保住。
- 老师改过某一步（内容指纹变化）：该步骤的结论自动**退回为未确认**，但记录仍留在复核列表中，直到复核员重新确认。
- 老师删除某一步：对应复核记录以「编排端已删除」形式保留在列表中，由复核员决定移除。
- 对账面板内置失败模拟开关，便于演练断网、两侧失败与按侧重试。

## 功能

- 课程模块：创建多个模块，维护模块目标、主题色和学习步骤。
- 步骤编排：每个步骤支持示范、讲解、练习类型，以及时长和入门/进阶/挑战难度标签。
- 动作素材：记录示范片段名称、可选的本地素材地址、手形说明、主要动作区域和镜头角度。
- 字幕与无障碍：设置字幕文本、字幕位置和替代文本，并在预览中标记字幕与动作区域冲突。
- 学习依赖：选择前置步骤，检查前置项不存在或指向后续步骤的跳级问题。
- 练习设计：记录练习任务、反馈方式和常见错误清单。
- 设备预览：在手机 9:16 和平板 4:3 视图间切换，并运行带检查点的动作时间线。
- 发布前检查：检查字幕遮挡、步骤跳级、替代文本缺失、练习反馈不完整和常见错误缺失。
- 状态流转：支持草稿、提交复核、退回修改、冻结版本和基于冻结版本创建修订版。
- 离线编辑：所有修改保存在各自的 `localStorage` 键中；浏览器离线或刷新后可继续编辑。
- 键盘操作（编排端）：`⌘/Ctrl + Z` 撤销、`⇧⌘/Ctrl + Z` 重做、`⌘/Ctrl + S` 保存草稿、`Alt + ↑/↓` 调整步骤顺序。

## 验证

```bash
node scripts/verify-reconcile.mjs
```

脚本用内存存储垫片跑通：离线记意见、联网按步骤编号对账、两版并排、逐条认、失败按侧重试、已确认结论保护、老师改步骤退回未确认、删步骤保留孤儿记录、双端存储隔离等场景。


## 技术栈

- Stencil 4
- TypeScript 5
- Ionic 9
- Ionic Core CSS

## 开发

```bash
npm install
npm run dev
```

Stencil 开发服务器默认监听 `3333` 端口，并启用监听构建。

## 构建

```bash
npm run build
```

生产静态文件输出到 `www/`。构建会同时生成 Stencil 分发包和组件文档。

## Docker

```bash
docker build -t sologsb-1012 .
docker run --rm -p 10012:80 sologsb-1012
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10012`。
